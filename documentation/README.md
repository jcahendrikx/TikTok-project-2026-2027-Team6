# TikTok-project-template-2026
This repository is a template for the Data preparation and programming skills in fall 2026. 

## Folder structure
We have three main folders: documentation, src, and data. 

Files documenting the process, such as this ReadMe, will be added to this documentation folder. 

The src folder will include files with code. 

Finally, the data folder is divided between a raw data subfolder and a processed data subfolder, where the respective data will be stored.
