\subsection{Data Downloading \&
Cleaning}\label{data-downloading-cleaning}

For each dataset, we downloaded the raw files from the specified
sources, verified file integrity, and removed duplicates. We then
standardized column names, handled missing values, and ensured
consistent data types across all tables. Finally, we performed basic
validation checks to confirm the cleaned data was ready for analysis.
The exact codes are recorded in the respective downloading and cleaning
files:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Video View:

  \begin{itemize}
  \tightlist
  \item
    \texttt{src/downloading\_videodata\_script.R}
  \end{itemize}
\item
  Sessions:

  \begin{itemize}
  \item
    \texttt{src/Session\_analysis\_alex/data\_session\_download.R}
  \item
    \texttt{src/Session\_analysis\_alex/data\_session\_cleaning.R}
  \end{itemize}
\item
  Watch Events:

  \begin{itemize}
  \item
    \texttt{src/watch\_events\_analysis/download\_watch\_events.R}
  \item
    \texttt{src/watch\_events\_analysis/cleaning\_watch\_events.R}
  \end{itemize}
\end{enumerate}

This summary document focuses purely on the actual analyses and
regressions performed, meaning that no more attention will be given on
the data cleaning process.
