4. Histogram of Watched Videos Distribution of Users

user_totals <- sessions %>% #Aggregate videos watched per user
  group_by(user_id) %>%
  summarise(total_videos = sum(videos_viewed, na.rm = TRUE), .groups = "drop")

video_distribution <- user_totals %>% #Frequency of each total videos
  group_by(total_videos) %>%
  summarise(user_count = n(), .groups = "drop")


ggplot(user_totals, aes(x = total_videos)) + # Plot the distribution as a histogram
  geom_histogram(binwidth = 10, fill = "#6497b1", color = "white") +
  labs(
    title = "Distribution of User Video Viewing",
    subtitle = "Bar Width = 10 Videos",
    x = "Total Videos Watched",
    y = "Number of Users"
  ) +
  theme_minimal()
ggsave(here("output", "session_analysis", "histogram_videos_per_user.png"))

6. Scatter Plot Sessions and Video Watched per User

A similar distribution is seen in the two graphs above, suggesting a possible association between the number of sessions and videos watched per user. Therefore, a scatter plot will be used to examine this relationship further.

user_summary <- sessions %>% #Recreate the two variables as they both existed in seperate stored dataframes
  group_by(user_id) %>%
  summarise(
    total_videos = sum(videos_viewed, na.rm = TRUE),
    num_sessions = n(),
    .groups = "drop"
  )

ggplot(user_summary, aes(x = num_sessions, y = total_videos)) +
  geom_point(color = "#6497b1", alpha = 0.6, size = 2) +
  geom_smooth(method = "lm", se = FALSE, color = "black", linetype = "dashed") +
  labs(
    title = "Scatterplot: Videos Watched vs Sessions per User",
    x = "Number of Sessions",
    y = "Total Videos Watched"
  ) +
  theme_minimal()
`geom_smooth()` using formula = 'y ~ x'
ggsave(here("output", "session_analysis", "scatter_sessions_vs_videos.png"))
Saving 7 x 5 in image
`geom_smooth()` using formula = 'y ~ x'

The scatter plot and the included black dashed regression line show a clear linear correlation between the number of sessions and number of videos watched. While this is no clear sign of causation, it can be argued that on average, when the number of sessions per user increases, the number of videos watched per user also increases.

Most users show moderate engagement, but both videos watched and session counts are right-skewed with some highly active outliers. Clear positive correlations exist between session frequency, session duration, and the number of videos watched, highlighting that more active users tend to watch more content
